# Training / Baselines

This folder contains the statistical benchmark models used to compare with the ensemble learning approach. The baselines offer a straightforward reference for accuracy, trend capture, and seasonal pattern modeling.

## Files

- `linear_regression.py` — trains the linear regression baseline on engineered features.
- `sarima.py` — trains the SARIMA baseline for seasonal time series forecasting.
- `__init__.py` — marks the package for import.
